## 做得好的地方

- bnb nf4 的结论是实测出来的（三条独立证据），没有跟着旧报告转述；
- 批量/等待/落盘链路在长任务下没丢 id（pending 机制）；
- 看板与 picks 共享同一份数据，人工挑选和 agent 挑选不会打架。

## 下次重点关注

1. 任何「精选/推荐」前，先写出**可验证的关系条件**，逐张核对；
2. 先确认目标环境（DSH 内 / 外部浏览器），再写「自动打开」；
3. UI 先定规范（色/字号/间距）再写组件；
4. 失败先归因到「模型能力 / 提示词 / 参数」三类，再动手。
