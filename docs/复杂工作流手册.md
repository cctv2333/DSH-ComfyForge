# 复杂工作流手册（参考图 / LoRA / 淘汰）

> 针对「模型不知道 C-130 长什么样」这类问题：文本只给语义，给不了形状。
> 解决办法不是继续改提示词，而是**给条件**：参考图、LoRA、或结构约束。

## 1. 为什么文本说不动

| 层 | 模型能接收 | 例子 |
|---|---|---|
| 文本 | 语义标签、风格词、关系 | "C-130" 只是一个没见过的 token 组合 |
| 图像条件 | 形状、结构、配色、构图 | 一张真机照片 / 线稿 |
| 权重 | 特定对象/画风的先验 | LoRA（如某画师、某机型） |

本地小模型 + 4bit 量化，训练数据里对"C-130"的概念很弱，提示词里加形容词也补不出机翼位置和发动机形态。
实测：写 `C-130 Hercules, high wing, four turboprop` 直出三次，全是四发**客机**（下单翼、喷气）。

## 2. 三条解法（按成本从低到高）

### A. 参考图条件（推荐先做）
- **IPAdapter**：把参考图编码成条件注入，最“懂样子”；
- **ControlNet**（Canny/Depth/Lineart）：把参考图的**结构**搬过来，最“守构图”；
- **img2img**：把参考图当起点，denoise 0.35–0.55，改动最小但最稳（**本机已可用**）。

本机现状：`models/ipadapter` 不存在、`clip_vision` 空、`controlnet` 空 → **A 的前两项没装，只有 img2img**。

### B. LoRA
- 装现成 LoRA：`models/loras` 现在是空的；放进去后 `LoraLoader` 就能接（`comfy_models` 会列出来）；
- 适合「固定画风/固定角色/固定机型」。

### C. 自己训练 LoRA
- 需要 20–50 张同一对象/画风的图 + 训练脚本（kohya_ss 等），本机没有；
- 成本高，但对「必须一模一样」的对象是唯一可靠解。

## 3. 在没装参考模型之前的替代法（已实现）

**分开渲染 + 合成 + 局部重绘**：

1. 用 img2img 单独渲染目标对象（哪怕背景是乱的），得到「形状正确」的版本；
2. `comfy_composite` 把它按 box 贴进场景（羽化接缝）；
3. `comfy_edit` 对贴入区域做一次局部重绘，让光影/风格融合；
4. `comfy_look` 看整体，`comfy_region` 看接缝。

这条链路不需要任何新模型，缺点是要多几步、且大角度透视时合成会不自然。

## 4. 迭代循环（这次实际跑的）

```
文本 → 生成 4 张 → 整体看（comfy_look）
  → 找出具体错误（机型错 / 文字乱 / 手崩）
  → 判断归因：语义？缺知识？采样？
  → 缺知识 → 参考图 / LoRA / 局部重绘
  → 再整体看 → 再定位 → 再修
  → 满意后进精选（picks）
```

## 5. 淘汰：能自动，但不能瞎删

`comfy_triage` 的规则（只认客观缺陷）：

| 判据 | 阈值 | 说明 |
|---|---|---|
| 读不出 | 解析失败 | 文件损坏 |
| 近似纯色 | contrast < 0.02 或 entropy < 3 | 黑图/白图/废片 |
| 死糊 | lap512 < 5 | 参数错/中断产物 |
| 过小 | 边长 < 256 | 尺寸设错 |
| 重复 | 均值哈希汉明距离 ≤ 2 | 同 seed 重复跑 |

- **不删除**，移动到 `<dir>/_trash/<时间戳>/`，写 `manifest.json`（原因 + 原路径）；
- **picks 里的图永不移动**；
- `comfy_triage(action="restore")` 一键搬回。

审美/语义好坏**不进自动淘汰**——那是人（或视觉模型）的判断；工具只负责把明显废片挑出来，并把决定权留给人。

## 6. 要补的模型（按性价比）

| 用途 | 模型 | 大小 | 状态 |
|---|---|---|---|
| 参考图（结构） | ControlNet Union Pro 2.0（FLUX） | 3.99GB | **已装（实测通过）** |
| 参考图（外观） | FLUX IPAdapter / Redux | 1–2GB + clip_vision 2.5GB | 未装 |
| 放大 | 4x-UltraSharp 等 | 60–200MB | 未装 |
| 画风/角色 | 现成 LoRA | 50–300MB | 未装 |

装了前两项，"模型不知道长什么样"才算真正解决；在此之前，只能用第 3 节的替代法。

## 7. 实测：A 线打通（2026-11-04）

- 模型：`flux-cn-union-pro-2.0.safetensors`（3.99GB，hf-mirror + aria2 16 连接）
- 参考：Wikimedia 的 C-130 实机照片（公共领域）
- 链路：`LoadImage → ImageScale(1024) → Canny(0.4/0.8) → ControlNetApplyAdvanced(strength 0.65, 必须接 vae) → KSampler`
- 结果：**文本直出三次都是四发客机；给了 Canny 结构后，第一次就画出高翼四涡桨的 C-130。**

踩到的坑：`ControlNetApplyAdvanced` 的 `vae` 是可选输入，但 FLUX 的 controlnet 不带就会报
`This Controlnet needs a VAE but none was provided`——必须把 VAELoader 接进这个节点。

局限：参考图是净底照片，输出也是"白底插画"；要放进街景还需要「控制画布 + 蒙版局部重绘」，
不是直接就能用。
