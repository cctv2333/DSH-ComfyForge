## 我踩坏过的地方（别重蹈）

1. **顺序写反**：先 `set({rightbar:true})` 隐藏浮层、再去 `openTab`。openTab 一抛错 →
   "药丸没了、tab 也没有"，用户看到的就是"什么都没有"。
   规则：**只有确认 tab 真的可见，才能隐藏兜底入口。**
2. **`guide` 字段的形状是猜的**（用了 `label`/`title`/`description`/`order`），
   写完右侧栏「开始」页变成空白，且 `Ctrl+R` 不恢复（布局被写进了会话状态）。
   要动它必须先弄清形状，且准备好"这一页会空白到下次重启"的代价。
3. 端口每次重启都变（53598→…→60369），localStorage 按 origin 分，浮层展开状态、
   可能的 tab 布局都因此重置 —— 很多"又消失了"其实是这个原因。

## 下一步唯一值得试的入口（可验证，不动 guide）

`sidebar.right.tab.guide.actions`（list，root 作用域）—— 它是「开始」页上
**「更多工具」那张卡的菜单行**，常驻、不依赖我的 tab 是否开着。
README 里的口径：每个注册项接收 `entries`、`onOpen(id)`、`onPinnedChange(id,pinned)`、`onDismiss()`；
`onOpen(id)` 就是"在该页位置打开这张卡的标签类型"。

所以：注册一行「Comfy 工作台」，`onClick: () => onOpen('comfy')`。
这条路的入口由 DSH 自己渲染，只要「开始」页在，入口就在 —— 不依赖 openTab 是否成功。

验证顺序（每一步都要截图看，别连着改）：
1. 只注册 guide.actions 一行，确认「开始 → 更多工具」里出现它，且页面没变空白；
2. 点它，确认右栏出现 Comfy tab；
3. 关掉 tab，再点一次，确认能回来；
4. 全通过后再决定要不要删浮层。
